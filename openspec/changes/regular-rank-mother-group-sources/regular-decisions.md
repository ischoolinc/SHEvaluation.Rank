# 定期評量專用決策草案

狀態：已於 2026-10-30 核准下列建議方案，並授權 Apply。核准是政策決定，不表示功能已實作。學期參照依據見 semester-reference.md。D02、D05、D06、D07、D08 採用該參照方案。

## D01：三種來源皆開放目標期間

建議：三種來源都可選歷年學年度與學期，預設系統目前期間。選目前來源時標示「依目前學生母群計算指定期間成績」，不承諾重建當時名冊。此方向依原始定期需求「完整開放歷年」，不照搬學期實作的目前來源鎖定。

驗收：系統 115-1，選目標 113-2、目前來源時，科目／成績只查 113-2，母群仍為目前符合一般＋延修資格者；若無修課不回退 115-1。

## D03：來源批次可跨期間及跨考試

建議：歷史批次只提供母群，可與目標期間及目標 exam ID 不同。來源條件不能覆寫目標；第二畫面與計算確認同時顯示來源批次／期間／考試和目標期間／考試。來源批次無法唯一識別其考試時阻擋載入，不能由名稱任取 ID。

驗收：來源 113-2 第一次定期評量，目標 114-2 第二次定期評量，使用來源母群及目標第二次成績；不得沿用來源科目與分數。

## D04：先載入母群，再確認目標科目

建議在第一畫面保留三組科目，增加「載入／更新母群及科目」操作。流程為：選目標期間／考試及來源 → 背景載入候選母群 → 依該母群與目標課程／sce_take 取得科目 → 第一畫面確認三組科目 → 下一步顯示完整母群。

目前來源仍先保留原版一般＋延修、有班級及年級資格；歷史／Excel 不因目前無班級而漏課。科目候選使用所選、可解析排名年級的母群學生，不先依五旗標刪學生，也不先讀取完整分數。

變更目標期間／考試／年級／來源批次／匯入檔／影響母群的類別設定時，將載入狀態標成過期並禁止下一步；成功重載後才解除。三組既有勾選以科目名稱保留交集，新出現科目依既有不採計設定初始化，移除與新增項目在畫面告知；不自動進入第二頁。

來源載入或科目查詢失敗時，不用上一次名單配新條件繼續。沒有任何可用科目時留在條件頁提示。科目排序保留原信用／節數／科目排序方式。類別領域與一般科目的原版交集不變。

歷史人工加人會改變候選名單，須回第一頁更新科目並確認，成功後重返第二頁；保存原有學生已編輯的 Working 旗標，不重新套排除預設。新加入者才套初始規則。若操作取消保留原清單，不將新學生半途寫入。

## D09：人工加人比照學期，不套目前來源資格限制

建議：目前來源的「一般＋延修」僅適用自動產生名冊。歷史人工加人比照學期依學號查詢，不加狀態篩選；多筆即阻擋，不能先過濾掉其他狀態再宣稱唯一。帶入目前母群與年級並標示其資料來自目前主檔。

第一版保留既有 ContainsIdentity 對學生 ID 或相同學號的保守去重，攔下時明示原因；不改學期共用方法。無法解析年級仍留清單／快照，計算前提示且不產生該生五種排名。歷史／Excel 既有學生不因本政策再次篩選資格。

驗收：退學／離校等非一般狀態但學號唯一時可加入；同學號多狀態仍阻擋；相同學號已在清單不重複加入。這是歷史來源人工操作，不能擴張目前自動來源資格。

## D10：零結果及缺成年級保護

重新核對 SemesterRankPublishSql.ResultSelect：既有 guard 要求 detail_count > 0 且等於 score_count。因此「整次無明細則語句內失敗回滾」已有學期程式依據，不只是一項新建議。

定期建議：全體無明細、全不參與或全部無有效成績，整次失敗並保留所有舊有效排名。任何本次實際預計取代的年級若沒有新明細，也讓整次失敗；不能成功取代其他年級卻默默清空無成績年級。個別學生／科目無成績則依原公式不產生該項明細，不阻擋有其他有效明細的年級。

工作副本可解析年級與勾選年級交集為本次計算年級；沒有候選學生的勾選年級不納入取代範圍，確認框列出實際範圍。失效使用目標學年期、目標 exam ID、實際計算年級及定期評量 item_type；保留舊批次資料。

驗收：兩個實際計算年級中一個無任何新明細時，整次不發布；舊兩年級排名都維持。只有某生某科無成績而該年級其餘有明細時，成功計算並保留無成績學生快照。

## D10：跨用戶端並行

建議同一目標學年期與 exam ID 的發布互斥，先不按年級拆鎖，以涵蓋年級範圍重疊。鎖只涵蓋排名發布交易，不涵蓋使用者編輯清單。不同目標可各自發布。

具體鎖機制仍需獨立測試庫原型證明。單語句中加入 advisory lock 不足以自行證明正確：必須驗證等待取得鎖後的語句快照、舊有效列可見性、更新筆數與新矩陣唯一性。若現有閘道不能提供可靠原子互斥，發布維持阻擋並提出方案，不新增表或改成逐年級提交。

驗收：兩個獨立連線同時計算同期間同考試，包含部分重疊年級；第二次明確拒絕或在可靠序列化後重算，最終每個矩陣識別鍵只有一組有效結果。不得只測單一 Form 的按鈕防重入。

## 共同 UI 與組態

母群名稱唯讀；搜尋只改顯示、完整匯出與計算仍依完整底層清單。恢復作用於完整清單，按鈕明示「恢復全部學生初始參與」。歷史識別班級／座號若只查得到目前值，欄名與說明明示目前資料，不當作歷史值。

計算前確認目標、來源、實際年級、會取代的有效排名，以及「三組科目等學校設定會先保存，排名失敗時不回滾該設定」。取消不 Save。JSON v1 保留完整清單，不新增歷史識別欄位。
