# Task 4.5 五種參與與確認操作

狀態：確認頁使用共用 `MotherGroupConfirmList` 與 `MotherGroupConfirmGrid`。離線與合成 Grid 檢查通過。沒有操作 iSchool 畫面，也沒有手動開啟或取消匯出對話框。

## 已接上的操作

- 五種母群名稱唯讀，五種參與可個別修改。右鍵選單可把選取學生的一種排名設為參與或不參與。
- 搜尋只改變資料列可見性。2066 人搜尋後底層清單仍是 2066 人。
- 統計使用清單上的參與旗標，不查成績。
- 「恢復全部學生初始參與」回到進入確認頁時的初始值，作用於完整清單。
- 「匯出完整清單」寫出共用 13 欄 Excel。檢查直接建立工作簿，2066 人的最後資料列是第 2066 列，不受搜尋影響。缺狀態時不另外查資料庫。
- 上一步回到原條件 Form。使用者關閉確認頁也走同一條返回。
- 目前學生的班級與座號標明來自目前主檔。

## 未測

匯出檔對話框、取消對話框、清除搜尋的實際打字，以及 iSchool 裡的捲動與返回，都還沒有人工操作。這些留在 Task 8.4 與 8.7。
