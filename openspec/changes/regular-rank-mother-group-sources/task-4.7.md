# Task 4.7 同步後的定期政策隔離

狀態：重新對過目前共用類別。定期差異放在新的來源轉接，沒有修改學期資格、`MotherGroupInitialParticipation.Apply`、歷史目錄、還原或發布類別。

## D02、D05、D07

- D02：定期歷史目錄、舊 XML 與無快照降級本輪沒有實作。確認頁與載入按鈕明確停用歷史入口，不改呼叫學期目錄，也不把「名稱不是學期成績」當成定期批次。
- D05：空白類別不參與、衝突項不參與，沿用共用 `Apply`。歷史快照的空白科別不改成參與；這條只在 `Current` 發生。本輪沒有載入歷史快照，所以沒有把學期最新歷史預設套進定期。
- D07：排除類別先留來源名稱，再把五種初始參與設為 false，確認頁可以改回。定期目前來源傳 `MotherGroupSourceKind.Current`。延修不靠把 `IsRegular` 設成 true 來通過學期篩選。

## 回歸

`RegularRankOperationCheck` 用同一批學生比較兩個來源。學期 builder 只留一般生；定期來源同時留一般生與延修生，延修狀態碼是 2。空白科別在定期目前來源維持參與，空白類別不參與，排除類別只關旗標、不改名稱。

Excel 與歷史還原若在後續回合實作，必須分別傳 `Excel` 與 `HistorySnapshot`，不能改用學期畫面的最新預設。
