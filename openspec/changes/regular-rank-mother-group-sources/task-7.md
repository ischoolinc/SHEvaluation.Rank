# Task 7 原子發布

狀態：未完成，不能勾選。沒有 Task 2.4 結構證據，沒有執行寫入、回滾或兩個連線發布。計算與儲存入口固定停用。

## 已有的離線邊界

`RegularRankPublishPlan` 把有候選學生的年級列入取代範圍，沒有學生的勾選年級不列入。任一列入年級被標記為沒有新明細時，整次失敗。計畫固定為單次同成同敗，`PerGradeCommit` 是 false，而且 `ExecutionAllowed` 是 false。班排名視窗沒有年級時，計畫要求維持年級隔離。

`RegularRankCalculationGuard.TryEnter` 在入口停用時不會進入執行中狀態，編輯旗標維持可恢復。確認頁的計算按鈕與條件頁舊計算按鈕都會顯示阻擋訊息，不保存學校組態，也不寫排名。

`RegularRankExistingRankLookup` 在沒有結構證據時不產生、也不執行檢索語句。沒有猜測連線字串或欄位。

## 開放計算前仍須證明

- Task 2.4 的四表欄位、extension 型別、`matrix_dept`、限制、索引與既有查詢端。
- 全部參與時與基準逐筆一致。
- 批次、後續年級、矩陣、學生與明細失敗時四表及舊有效排名回滾。
- 兩個獨立連線同時發布重疊年級後，同一矩陣鍵只有一組有效結果。單頁防重入不能代替這項。
