# Spec Delta

## Purpose

定義學期成績固定排名初次開啟時，左下角如何顯示載入階段、完成後如何恢復說明，以及失敗時如何停在條件頁。

## ADDED Requirements

### Requirement: 左下角持續顯示載入階段
開啟學期成績固定排名時，系統 MUST 在既有左下角說明位置持續顯示目前階段，順序為畫面初始化、學校設定、學生類別、學生清單、年級清單。系統 MUST NOT 另開視窗，也 MUST NOT 顯示沒有依據的百分比。

#### Scenario: 正在載入學生清單
- **WHEN** 畫面正在載入學生清單
- **THEN** 左下角顯示學生清單階段，且不顯示百分比或其他階段

### Requirement: 載入完成恢復原本說明
五個階段都成功後，系統 MUST 恢復左下角原本的說明文字，並允許進入下一頁。原本說明文字為「說明：班、科、年排名會自動計算。分項成績擇優項目請參考成績計算規則。」

#### Scenario: 五個階段都成功
- **WHEN** 畫面初始化、學校設定、學生類別、學生清單與年級清單都成功
- **THEN** 左下角恢復原本說明文字，下一步可以進入確認母群

### Requirement: 載入失敗不得進入下一頁
任一階段失敗時，系統 MUST 在左下角顯示該階段與錯誤，MUST NOT 恢復原本說明，且下一步 MUST 維持停用。系統 MUST NOT 用這次未完成的類別或年級進入確認母群。

#### Scenario: 學生清單載入失敗
- **WHEN** 學生清單讀取失敗
- **THEN** 左下角顯示學生清單階段的錯誤，下一步維持停用，確認母群沒有這次的半套名單

### Requirement: 載入維持原篩選與擇優規則
載入過程 MUST NOT 改變學生篩選與擇優設定規則。學生 MUST 仍只含狀態為一般、有班級且年級有值者。設定檔有內容時 MUST 先取消擇優項目再依檔案勾回；設定檔為空時 MUST 維持畫面原有預設。

#### Scenario: 設定檔含部分擇優項目
- **WHEN** 學校設定檔含補考成績且不含重修成績
- **THEN** 載入完成後補考成績為勾選、重修成績為未勾選，學生範圍仍是一般、有班級且年級有值

### Requirement: 階段文字先顯示且資料執行緒已確認
系統 MUST 先顯示階段文字，再讀取該階段資料。學生、類別、學校設定及其關聯屬性未確認可離開畫面執行緒時，MUST 留在畫面執行緒，且關聯屬性與該次讀取使用同一執行緒。畫面控制項 MUST 在畫面執行緒更新。載入尚未成功結束時，下一步 MUST 維持停用。

#### Scenario: 關聯屬性尚未確認可離緒
- **WHEN** 學生資料的關聯屬性尚未確認可在背景執行緒使用
- **THEN** 學生清單與其年級條件仍在畫面執行緒讀取，且左下角已先顯示學生清單階段

#### Scenario: 載入尚未成功
- **WHEN** 任一載入階段尚未成功結束
- **THEN** 下一步維持停用

### Requirement: 下一步進行中不可重入
按下下一步後，系統 MUST 立刻用同一個旗標擋住目前學生、歷史批次與 Excel，並停用下一步。第二頁尚未完整開啟時 MUST NOT 再開始另一次下一步，也 MUST NOT 建立第二個背景工作。成功開啟第二頁後 MUST 解除旗標，且第一頁下一步維持停用。回到第一頁時 MUST 再啟用下一步。

#### Scenario: 連按下一步
- **WHEN** 下一步正在處理，使用者再次按下下一步
- **THEN** 不開始第二次處理，也不建立第二個背景工作

### Requirement: 下一步使用左下角提示
下一步 MUST 立刻把既有 labelX6 改成該來源的處理文字並先繪製。目前學生為「正在載入目前學生母群資料...」。歷史來源為「正在讀取歷史批次及母群資料...」。Excel 為「正在匯入 Excel 母群資料...」。成功、取消、失敗或沒有資料時 MUST 恢復原本說明。控制項更新 MUST 在畫面執行緒。不顯示沒有依據的百分比。

#### Scenario: 歷史來源按下下一步
- **WHEN** 使用者以歷史學期成績來源按下下一步
- **THEN** 左下角先顯示歷史讀取提示，完成或失敗後恢復原本說明

### Requirement: Excel 選檔留在畫面執行緒
Excel 的開啟檔案對話 MUST 留在畫面執行緒。取消選檔 MUST 恢復下一步與原本說明。檔案解析、學號查詢與驗證 MUST 離開畫面執行緒，且背景工作 MUST NOT 操作 WinForms 控制項。驗證成功後才顯示完整確認清單。

#### Scenario: 取消選檔
- **WHEN** 使用者關閉檔案對話而沒有選擇檔案
- **THEN** 下一步恢復可按，確認清單不建立
