# Spec Delta

## Purpose

定義學期排名母群的 Excel 匯入與匯出，包含學號加學生狀態的唯一對應、錯誤阻擋與相同 13 欄往返。

## ADDED Requirements

### Requirement: 匯入與匯出使用相同 13 欄
Excel 匯入與匯出 MUST 使用相同 13 欄，順序是：學號、姓名、學生狀態、年排名母群、班排名母群、科排名母群、類別一母群、類別二母群、年排名參與、班排名參與、科排名參與、類別一參與、類別二參與。學生狀態 MUST 必填，而且只接受一般、延修、休學、輟學、畢業或離校、刪除。這六個名稱依序對應 `student.status` 的 1、2、4、8、16、256。參與欄只接受「參與」或「不參與」。學號 MUST 保留前導零。

#### Scenario: 匯出確認清單
- **WHEN** 使用者匯出確認清單的工作內容，且每位學生的狀態都在上述六個數字之中
- **THEN** 檔案含上述 13 欄，第 3 欄是對應中文，並寫出畫面上的五種母群名稱與五種參與狀態

#### Scenario: 匯出前補上缺值的目前狀態
- **WHEN** 確認清單有學生的 `Status` 是空的，其餘學生已有允許的狀態
- **THEN** 系統只對空值的 `student.id` 發同一句查詢，取得目前 `student.status`，不用學號查詢，也不逐位學生查詢

#### Scenario: 匯出時學生狀態無法對照
- **WHEN** 以 `student.id` 查不到學生、查詢失敗、同一 id 超過一筆，或狀態不是 1、2、4、8、16、256
- **THEN** 系統明確回報該生，不產生把狀態寫成一般的匯出檔，也不改母群名稱或參與狀態

#### Scenario: 參與值不在允許範圍
- **WHEN** 匯入檔的某個參與欄不是「參與」或「不參與」
- **THEN** 系統回報該列異常，且不進入確認清單

#### Scenario: 學生狀態空白或不在對照表
- **WHEN** 匯入列的學生狀態是空白，或不是上述六個中文
- **THEN** 系統回報該 Excel 列號與錯誤內容，且整份檔案不進入確認清單

### Requirement: 學號加學生狀態必須唯一對應到一名學生
系統 MUST 把學生狀態中文轉成 `student.status` 數字，再以 `student.student_number` 與 `student.status` 一起查詢。查到 0 筆時 MUST 回報找不到學生。查到 1 筆時 MUST 使用該筆 `student.id`。查到超過 1 筆時 MUST 回報身分不唯一，且 MUST NOT 任選一筆。相同學號、不同學生狀態 MUST 允許各自匯入。相同學號、相同學生狀態在 Excel 重複時 MUST 回報重複資料。同一 `student.id` MUST NOT 重複出現在確認清單。學號空白、狀態無法對照、檔內重複、查無、多筆，或因此無法唯一對應時，系統 MUST 回報異常並拒絕該次匯入。姓名與學生主檔不一致時，系統 MUST 仍使用 `student.name` 與解析出的學生 ID，並保留可辨識的姓名差異警告。

#### Scenario: 學號與狀態對到唯一學生
- **WHEN** 匯入的學號與學生狀態在學生資料中恰有一筆
- **THEN** 確認清單使用該筆 `student.id`，不以姓名另找學生

#### Scenario: 相同學號但狀態不同
- **WHEN** 匯入檔有兩列學號相同，一列學生狀態是一般，另一列是延修，而且資料庫各自恰有一筆不同的 `student.id`
- **THEN** 兩列都進入確認清單，分別使用自己的 `student.id`

#### Scenario: 相同學號與相同狀態重複
- **WHEN** 匯入檔有兩列學號與學生狀態都相同
- **THEN** 系統回報重複資料與列號，且不建立確認清單

#### Scenario: 學號與狀態有多筆學生
- **WHEN** 同一個學號與同一個學生狀態在學生資料中有兩筆以上
- **THEN** 系統回報身分不唯一，且不建立確認清單

#### Scenario: 同一學生識別出現兩次
- **WHEN** 匯入檔的兩列解析到同一個 `student.id`
- **THEN** 系統回報重複，且不建立確認清單

#### Scenario: 檔案含有任一對應錯誤
- **WHEN** 匯入檔有一列學號空白、學生狀態空白或狀態無法對照，其餘列有效
- **THEN** 整次匯入失敗，有效列也不進入計算

### Requirement: Excel 模式提供可匯入的空白範本
「下載匯入範本」MUST 以另存新檔產生 `.xlsx`。檔案 MUST 重用既有 13 欄表頭，A 欄學號 MUST 預設為文字格式，而且 MUST 只含表頭與格式，不得把示意資料放進工作表。填寫說明 MUST 依既有匯入器列出必填欄位、學生狀態可填值、空白規則與錯誤處理，並說明系統以學號加學生狀態比對、學號如 `001234` 須保留前導零，以及五個參與欄都要填「參與」或「不參與」。

「選擇 Excel 檔案」MUST 沿用既有選檔與匯入驗證。使用者取消選檔時 MUST 回到可操作的設定頁，不得留下進行中的下一步。

#### Scenario: 下載空白範本
- **WHEN** 使用者在 Excel 來源按下載匯入範本並指定新檔路徑
- **THEN** 產生的檔案有 13 欄表頭、學號欄為文字格式，而且沒有示意資料列

#### Scenario: 保留前導零並拒絕非法參與值
- **WHEN** 使用者用範本填入一筆學號 `001234` 且學生狀態可對到測試資料的列，以及另一份把參與欄填成「參與」「不參與」以外文字的檔案
- **THEN** 有效列匯入後學號仍是 `001234`；非法參與值由既有匯入器回報錯誤，而且不建立確認清單

#### Scenario: 取消選檔
- **WHEN** 使用者按選擇 Excel 檔案後取消對話框
- **THEN** 設定頁可以繼續操作，沒有進入確認清單

### Requirement: 匯入結果仍接受確認清單的預設規則
通過驗證的 Excel MUST 成為母群來源。檔內母群名稱與參與狀態是初始來源值；進入確認清單時 MUST 再套用圖1不排名學生類別的預設規則。計算 MUST 使用套用規則並經使用者調整後的確認清單。五種母群名稱與參與規則 MUST 維持不變。

#### Scenario: 再次匯入同一份匯出檔
- **WHEN** 使用者匯出確認清單後，再次匯入這 13 欄的同一份檔，且其中學生符合圖1不排名學生類別
- **THEN** 學號加學生狀態對回同一個 `student.id`，五種母群名稱與匯出檔相同，但該生五種初始參與為不參與，因此與匯出檔的參與值不同

#### Scenario: 檔內參與被不排名預設覆寫
- **WHEN** 匯入檔將某生五種排名都設為參與，且該生符合不排名學生類別
- **THEN** 確認清單仍顯示檔內的五種母群名稱，五種初始參與狀態為不參與，使用者可再改回參與
